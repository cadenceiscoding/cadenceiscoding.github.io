## About the Project
Inner Machinations uses xenopoetics to explore how computer science can be integrated with, overlayed on and thought about in creative writing.

## How to Use
While you are free to explore the website however you'd like, the following guide ensures each embedded piece will be viewed:
1. Select the 'index.html' file from the submitted folder, and open with Chrome (or your preferred browser).
2. Move the mouse around over the banner at the top of the page. Hover over it a moment to see a title appear.
3. Note the 'Home' and 'Artist's Statement' buttons on the page. These are accessible from every page on the website.
4. Scroll down to view the first piece, "if-then-else."
5. Hover over the image displaying "if-then-else" and notice the pop-up that appears. Click on it to navigate to the page for the next piece, "Fix (Ctrl+l)."
6. Note the 'Previous' and 'Next' buttons at the bottom of the page. From this page onwards, these buttons will be present on every page. Use them to navigate back and forth through the website.
7. Click 'Next' to view the page for the next piece, "Omnipotence."
8. Note that on this page, the diagram of the Turing Machine Reconfigure uses shorthand notations to describe more complex transitions. The 'w' and 'w'' text within the poem stanzas can be hovered over to see their assigned values.
9. Click 'Next' to view the page for the next piece, "Source code."
10. Note that the text in this piece is a runnable program (The code for this piece is included in the submitted folder, within source-code.py. Open it in an IDE and run it to see the output! Try running it multiple times and see how it changes).
11. Click 'Next' to view the page for the next piece, "Understanding."
12. Note that the structure of this piece follows a standard proof for showing a given language is not semidecidable (by reducing from a problem known not to be semidecidable, such as the non-halting problem. The diagram at the bottom left of the page shows that the EqTMs problem falls outside the decidable and semidecidable sets of problems).
13. Click 'Next' to view the page for the next piece, "Acceptance."
14. The theoretical computational model shown on this page is called a Deterministic Finite Automaton, a machine with a finite number of states that accepts or rejects an input string by moving through a sequence of states, and checking if the state it halted in was accepting. 
15. Click 'Next' to view the page for the next piece, "Memory Allocation."
16. This piece combines fragments of c code used to allocate and free memory with poetry.
17. Click 'Next' to view the page for the next piece, "easy access."
18. This piece integrates Linux commands into poetry. 
19. Click 'Next' to view the page for the next piece, "Depth-First Search."
20. This piece integrates pseudocode for a depth first search traversal of a graph into poetry.
21. Click 'Next' to view the Artist's Statement page.
22. Right click the 'Artist's Statement' header on this page and select 'Inspect.' A piece of automatic writing is embedded in a comment of this pages' html code.
