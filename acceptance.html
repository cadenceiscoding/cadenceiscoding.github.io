Let input alphabet ∑ = {the English alphabet, ' ', '.', ',', '\n'} (all letters in the English alphabet, spaces, periods, commas and newline characters)

Formal description of this DFA:

States: 

  • q0: start of a word, no 'a' has been seen yet
  • q1 (accepting): word where an 'a' has been seen
  • q2: \n seen (denoting the end of a line, DFA stays in this state until a new word begins or an invalid line begins)
  • d: dead state

Transitions:

From q0: 

  • If an 'a' is read, go to q1
  • If a \n, space, comma or period is read, go to d
  • Else stay in q0

From q1:

  • If a space is read, go to q0 (new word starting)
  • If a \n is read, go to q2 (new line of poem starting)
  • Else stay in q1

From q2:

  • If a \n is read, stay in q2 (accounts for lines with no characters on them other than \n which separate stanzas)
  • If a space, comma or period is read, go to d (invalid start to a line)
  • If an 'a' is read, go to q1
  • Else go to q0 (new word starting)

From d:

  • On all input, stay in d

Ex. accepted input string = "at dawn another anomaly starts,\nthat place underneath creating space anew,\ngrasping tears and pain.\n\nan aged heart became a roaring cavity,\nstartled angels anguishing above.\n\nearly death began,\ncatching many unaware,\ntaking targets\nall around.\n\nplease that machine,\nexact vengeance and\nchannel agony towards\ninternal intricacies."
