If Understanding exists, C = Understanding(R(<M, w>)) semidecides ¬H: where M? halts on nothing.

  • <M, w> ∊ ¬H: M does not halt on w, so M# gets stuck in step 1.3 and halts on nothing. Therefore M# never accepts any input. L(M#) = L(M?) = Ø, so Understanding accepts.
  • <M, w> ∉ ¬H: M halts on w, so M# halts on everything and always accepts. L(M#) = ∑ and L(M?) = Ø, so Understanding does not accept.

But no machine to semidecide ¬H can exist, so neither does Understanding.
