Artist's Statement

Inner Machinations is a project that engages with xenopoetics by combining concepts and syntax from computer science with creative writing. I utilized languages such as Java, Python and C to defamiliarize the themes explored in some of these pieces, challenging the reader to think more deeply. Combining theoretical computational models like Turing machines and Deterministic Finite Automata with my writing allowed me to step outside conventional forms of narrative expression. The project was driven by a curiosity toward combining my educational disciplines that I otherwise tend to compartmentalize, and seeing how their overlap enriched the possibilities of form. 

  • if-then-else uses the structure of conditional statements in Java as a framework for obsessive thoughts about the past, and the regrets that stem from them.

  • Fix (Ctrl + l) became possible as a result of if-then-else being written within a Java file, removing all words my Integrated Development Environment flagged as causing errors. These pieces are thus related, Fix (Ctrl + l) having a more disjointed, raw feel that an unconscious stream of thought would reflect.

  • Omnipotence uses a Turing machine that takes the first instance of ‘an’ in a given input string and shifts it to the end. The input string ‘angle’ thus becomes ‘glean,’ tying into the larger piece in its exploration of personality, perspective and the warped nature of these concepts.

  • Source Code uses the random library in a Python program to construct a randomized poem. Two of the lines within the piece are dependent on lists defined at the beginning of the program, reflecting the inconsistencies of familial relationships.

  • Understanding uses a reduction proof to show the EqTMs language is not semidecidable, relating the uncertainty of the problem to a fear of being misunderstood, and the resulting reluctance to be vulnerable at all.

  • Acceptance uses a Deterministic Finite Automata to introduce constraint, requiring that every word in the poem contains the letter a. This resulted in creative diction use and enhanced imagery.

  • Memory Allocation uses lines of C code regarding the allocation and freeing of memory to explore a fear of forgetting, and how personality can change with that process.

  • easy access uses Linux commands regarding files and permissions to reflect the frustrating contradictions of expressing and experiencing feminine desire.

  • Depth-First Search combines pseudocode for the depth-first traversal of a graph with poetry exploring blind trust and the dangers of loving someone for their potential.

  • Conjecture uses automatic writing to engage with the themes explored throughout this project and draw it to a thought-provoking close.
